# ThesisForge

An AI-powered Streamlit web application designed to help students and researchers analyze, chat, and manage their thesis work efficiently.

## Features
* Secure, password-protected input for your API key.
* Interactive real-time chat interface.
* Dynamic response rendering for instant academic writing assistance and brainstorming.
